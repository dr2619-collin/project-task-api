# Project and Task Management API

This repository contains the course demonstration project for SDEV 3310. The application grows incrementally as new FastAPI and software-development concepts are introduced.

The `main` branch contains only this guide. Course code is organized into cumulative module branches so students can inspect the application at a specific point in the course without seeing later solutions.

## Module branches

| Branch | Content |
|---|---|
| `module-01` | Course orientation and API basics |
| `module-02` | REST, CRUD, status codes, and Project routes |
| `module-03` | Pydantic data models, field constraints, and request validation |
| `module-04` | OpenAPI contracts, API design, and generated documentation |

Each module branch builds on the preceding module. The final module branch will contain the completed demonstration application.

To view a module locally, run:

```bash
git switch module-01
```
